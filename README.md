# Кейс «AI-маркетолог для Города» — Мини-СЕО Т-Банка

Решение бизнес-кейса отбора на программу Мини-СЕО. Задача: спроектировать AI-маркетолога, который сам ведёт маркетинговую кампанию раздела «Город» от гипотезы до разбора итогов. Отправку клиентам утверждает человек.

Итог: презентация на 10–12 слайдов (ссылка на Яндекс Диске) и этот репозиторий с полной документацией.

## Структура

| Папка | Что внутри |
| --- | --- |
| `Условия кейса.pdf` | Исходные условия (локально, в репозиторий не попадают) |
| `docs/` | Документация по шести вопросам кейса, допущения, вопросы организаторам |
| `diagrams/` | Схемы: процесс «как было / как станет» (BPMN), архитектура, логика судьи |
| `model/` | Экономическая модель: экономия FTE и дней, стоимость системы, окупаемость |
| `slides/` | Тексты слайдов и финальная презентация |
